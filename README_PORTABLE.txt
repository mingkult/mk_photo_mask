照片隱私遮蔽工具｜AI 完全離線 Windows 可攜版 v3.2
=====================================================

快速使用
1. 將整個 mk_photo_mask 資料夾解壓縮到電腦或隨身碟。
2. 「照片隱私遮蔽工具.exe」已包含在壓縮檔內，可直接雙擊啟動。
3. 第一次也可雙擊 start.bat；畫面會明確顯示捷徑建立成功或失敗。
4. 捷徑建立後，可使用 EXE 或捷徑啟動。

可攜性
- 所有程式與 AI 模型都在本資料夾內，不需要安裝，不依賴固定磁碟代號。
- 搬移資料夾後先執行一次 start.bat，捷徑會自動更新為新路徑。
- AI 辨識與照片處理均在本機瀏覽器完成，不會上傳照片。

圖示
- icon.ico 是程式唯一的應用程式圖示來源。
- 內建的 Windows EXE、啟動捷徑、PowerShell 主控台視窗與網頁分頁均使用此圖示。

系統需求
- Windows 10 或 Windows 11。
- Windows PowerShell 5.1。
- Microsoft Edge、Google Chrome 或其他現代瀏覽器。

注意：請勿單獨移動 EXE；必須保留整個 mk_photo_mask 資料夾及所有子資料夾。
