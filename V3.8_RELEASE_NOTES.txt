mk_photo_mask V3.8

本版重點：照片可持續追加 + 工作專案容量與 ZIP 記憶體最佳化。

1. 工作中繼續加入照片
   - 左側「已選照片」新增「＋ 加入照片」。
   - 已經做好的 AI、人工作業、遮罩、Undo／Redo 不會因新增照片而消失。
   - 將照片拖到已載入工作區，也會自動以追加方式加入。

2. 重複與張數管理
   - 追加時會自動略過相同檔名、大小與最後修改時間的重複照片。
   - 最多仍維持 100 張；依目前剩餘名額決定可再加入幾張並清楚提示。

3. 清除全部更安全
   - 不再用重新整理頁面清空。
   - 直接清空工作區並保留程式與 AI 環境。
   - 若還有未輸出修改，會先跳出確認提示。

4. .mkpm schema v2
   - 未修改照片不再同時保存「原圖 + current PNG」兩份內容。
   - 只有真正套用過遮罩、像素已改變的照片才保存 current PNG。
   - AI 框／手動框尚未套用時仍會完整寫入 manifest，可正常恢復。
   - 可讀取 V3.7 schema v1 舊專案。

5. ZIP 記憶體最佳化
   - ZIP 封裝改為直接引用來源 Blob。
   - CRC32 計算完成後不再把整份位元組陣列長時間保存在 ZIP 結構內，降低大型 ZIP／專案檔的尖峰 RAM。
