mk_photo_mask V3.7

- 新增「儲存工作／載入工作」：可將目前照片、已套用結果、AI 框、手動框、勾選狀態與遮罩設定保存為 .mkpm 工作專案檔，之後可再載入繼續處理。
- 工作專案會一併保存原始照片與目前處理畫面；自訂貼圖也會隨專案保存。
- 載入工作專案後會恢復目前照片、處理狀態、AI／手動框與作用中的照片；為避免專案檔過大，Undo／Redo patch 不寫入專案，載入後從新的操作開始累積。
- 原始照片記憶體最佳化：不再為每張照片常駐保存完整 ImageData；需要「取消修改／全部重來」時改由原始 File 重新解碼，顯著降低多張高解析照片的 RAM 壓力。
- 單張重設、批次重設與全部重來改為非同步逐張恢復，並顯示處理進度，避免大量照片時介面長時間卡住。
- 保留 V3.6 的未輸出篩選、下載狀態、Undo／Redo 記憶體上限、批次管理、AI＋手動同步及完全離線架構。
- Windows build 預設版本更新為 3.7。
