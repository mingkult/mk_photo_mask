mk_photo_mask V3.7

本版重點：工作專案保存／恢復 + 原始照片記憶體最佳化。

1. 儲存工作／載入工作
   - 新增 .mkpm 工作專案檔。
   - 保存原始照片、目前已處理畫面、AI 框、手動框、AI 勾選、作用中照片、篩選狀態與遮罩設定。
   - 若有自訂貼圖，也會一起保存。
   - 載入後可直接延續上次工作。

2. 專案檔安全設計
   - 專案完全在本機建立與讀取，不上傳網路。
   - 為避免專案檔過度膨脹，Undo／Redo 的 ImageData patch 不寫入專案；載入後 Undo／Redo 從新的操作重新累積。

3. 多圖 RAM 最佳化
   - 移除每張照片常駐的完整 original ImageData 備份。
   - 重設照片時由原始 File 重新解碼恢復。
   - 對多張高解析照片可節省大量常駐記憶體。

4. 重設流程優化
   - 單張、批次與全部重來改為非同步逐張處理。
   - 大量照片時會顯示進度並讓瀏覽器有機會更新畫面，降低假死感。

5. 相容性
   - 保留 V3.6 既有功能與操作方式。
   - Windows build 預設輸出版本更新為 3.7。
